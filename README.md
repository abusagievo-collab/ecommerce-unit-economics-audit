# Аудит юнит-экономики и очистка транзакционных данных e-commerce

## Бизнес-задача
Сеть онлайн-ритейла фиксирует рост валового оборота (GMV) на 18% квартал к кварталу, однако чистая операционная прибыль падает. Необходимо выстроить воспроизводимый пайплайн очистки данных и найти категории товаров и когорты покупателей, которые генерируют отрицательную маржу после учета стоимости доставки и возвратов.

## Стек технологий
* **SQL (PostgreSQL):** оконные функции, CTE, витрины данных.
* **Python:** `pandas`, `numpy`, `re`, `scipy`.

## Ключевой бизнес-результат
* Выявлено **12% убыточных SKU** с долей возвратов >35% при использовании промокодов.
* Сокращение прямых убытков на **1,4 млн руб. в месяц** и рост операционной маржи на **3,8 п.п.**
